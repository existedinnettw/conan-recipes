# VectorQuaternionMatrix

Packages [Library-VectorQuaternionMatrix](https://github.com/martinbudden/Library-VectorQuaternionMatrix)
0.4.10 as `vectorquaternionmatrix/0.4.10`. Requires C++20.

Use `find_package(vectorquaternionmatrix REQUIRED CONFIG)` and link
`vectorquaternionmatrix::vectorquaternionmatrix`. Headers include
`Quaternion.h`, `Matrix2x2.h`, `Matrix3x3.h`, `xy_type.h`, `xyz_type.h` and
`FastTrigonometry.h`. Builds the library source without the PlatformIO demo main.
